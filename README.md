# Параллельная обработка данных (Windows Forms)

Оконное приложение на C# с тремя вкладками, демонстрирующее использование современных технологий параллельной и асинхронной обработки данных в .NET:

- `Task`, `async`/`await`
- `Parallel` и MapReduce
- Потокобезопасные коллекции (`ConcurrentDictionary`)
- PLINQ vs LINQ
- Имитация микросервисной архитектуры

---


## 📌 Задачи

### 1. MapReduce: Подсчёт вхождений слов
- Обрабатывает **5 текстовых файлов** из папки `Texts`.
- Использует алгоритм **MapReduce**:
  - **Map**: параллельный подсчёт вхождений слов в каждом файле через `Parallel.ForEach`.
  - **Reduce**: агрегация результатов с помощью `ConcurrentDictionary<string, int>`.
- Выводит статистику: `слово → количество`.

### 2. Микросервисы: Имитация распределённой обработки заказов
- Генерируются:
  - Товары (`Goods`)
  - Склад (`Storage` с `ConcurrentDictionary<Goods, Info>`)
  - Заказы (`Order` с товарами, скидкой, адресом)
- Обработка каждого заказа проходит через три "сервиса":
  1. **Inventory Service** — проверка наличия товаров
  2. **Pricing Service** — расчёт итоговой стоимости со скидкой
  3. **Shipping Service** — расчёт срока доставки по адресу
- Каждый заказ обрабатывается в отдельной `Task`.
- Все этапы логируются в общий файл.
- Выводится статистика:
  - Сколько заказов обработано полностью
  - Сколько отменено из-за отсутствия товаров

### 3. Сравнение LINQ и PLINQ
- Генерация тестовых данных с помощью библиотеки **[Bogus](https://github.com/bchavez/Bogus)**:
  - Сотрудники (`Employee`)
  - Заказы (`Order`): 50–100 на сотрудника
- Выполняются три запроса:
  1. Заказы сотрудников, чьё имя начинается с указанной подстроки
  2. Заказы после заданной даты
  3. Сотрудники, отсортированные по средней сумме заказов (по убыванию)
- Для каждого запроса измеряется время выполнения:
  - Последовательно (`LINQ`)
  - Параллельно (`PLINQ` через `.AsParallel()`)
- Результаты и сравнение эффективности выводятся в интерфейсе.

## 🛠 Технологии
- Язык: **C#**

## 🚀 Как запустить

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ber17lino/ParallelWindowsForms.git
2. Убедитесь, что установлена .NET 8 SDK.
3. Создайте папку Texts в каталоге запуска приложения и поместите туда 5 текстовых файлов с расширением .txt (на английском языке).
   bin\Debug\net8.0-windows\Texts\
4. Откройте проект в Visual Studio или соберите через CLI:
   dotnet build
   dotnet run
5. Используйте интерфейс:
* Вкладка MapReduce → нажмите "Запустить задачу 1"
* Вкладка Микросервисы → нажмите "Запустить задачу 2"
* Вкладка LINQ vs PLINQ → укажите число сотрудников → нажмите "Запустить задачу 3"
